DEV CHEAT — стартовый проект Android

Что уже есть:
- собственное приложение с чёрно-фиолетовым оформлением;
- кнопка включения плавающего меню;
- перемещение меню пальцем;
- закрытие меню;
- запрос системного разрешения «Поверх других приложений».

Важно:
Это самостоятельная демонстрационная оболочка. В проекте нет внедрения в сторонние игры,
чтения/изменения их памяти, обхода античита или чужой системы лицензирования.

Сборка на телефоне:
1. Установи AndroidIDE из официального источника проекта.
2. Распакуй ZIP в память телефона.
3. В AndroidIDE открой папку DEV_Cheat как Gradle-проект.
4. Дождись синхронизации Gradle.
5. Выбери Build APK / Assemble Debug.
6. Установи созданный APK и при первом запуске разреши «Поверх других приложений».

Параметры:
- Package: dev.cheat
- Min Android: 6.0 (API 23)
- Compile SDK: 35
- Версия: 1.0

Если AndroidIDE сообщит об ошибке SDK или Gradle, пришли точный текст ошибки.
